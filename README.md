# Heatcalculator

Java-Anwendung zur groben Modellierung verschiedener Solaranlagen.

Das Projekt berechnet anhand von Sonnenstunden, Panelleistung und Anlagenabmessungen die benötigte Anzahl Solarpanels sowie den erwarteten täglichen und jährlichen Energieertrag.

Es werden drei Varianten abgebildet:

- Solarpanels auf einer Dachfläche
- Anlage mit vorgegebener Reihen- und Panelanzahl
- Solaranlage an einem Hang

## Technologien

Java, JavaFX und Maven

## Kontext

Entstanden im Rahmen des GIBB-Moduls 320 (Aug. – Okt. 2025) zum Erlernen der Grundlagen objektorientierter Programmierung.
